# Minas Caixa Real Estate Platform API Specification

## 1. Overview & Architecture

This document serves as the **Single Source of Truth (SOT)** for the reverse-engineered rental search and property management APIs powering **Minas Caixa Imóveis** (`https://www.minascaixaimoveis.com.br/`).

### 1.1 Platform Identification

- **Backend Platform**: PHP 7+ on Apache Web Server
- **Underlying CRM / Engine**: Imoview Real Estate CRM (`Api.php`)
- **Frontend Framework**: Bootstrap 3 + jQuery 2.2 + AJAX Client-side Rendering
- **Base URL**: `https://www.minascaixaimoveis.com.br`
- **Asset / Media CDN**: `https://cdn.imoview.com.br/minascaixa/Imoveis/`

### 1.2 Authentication & Access Control

All public search, filter, and detail endpoints are completely unauthenticated.
- **Tokens / Cookies**: None required (PHPSESSID cookie is generated by Apache/PHP but not required for API requests).
- **Origin / Referer**: Not strictly required; standard User-Agent header recommended.
- **Fail-Fast Boundary Guard**: Omitting any of the five mandatory search fields causes an internal server fatal error (`Curl failed with error #22: 500 Internal Server Error in /classes/Api.php on line 128`).

## 2. API Endpoints Specification

### 2.1. Rental Search Endpoint

- **URL**: `POST https://www.minascaixaimoveis.com.br/imoveis/ajax/`
- **Content-Type**: `application/x-www-form-urlencoded`
- **Response Format**: `application/json`

#### Mandatory Parameters:
| Parameter | Type | Required Value / Format | Purpose |
|:---|:---|:---|:---|
| `imovel[finalidade]` | string | `"aluguel"` | Filter for rental transactions |
| `imovel[valorde]` | string/int | `"0"` or positive integer | Minimum rental budget ceiling in BRL |
| `imovel[valorate]` | string/int | `"0"` or positive integer | Maximum rental budget ceiling in BRL (`0` = unbounded) |
| `imovel[pagina]` | string/int | `"1"`, `"2"`, ... | Page index (1-based) |
| `imovel[codigocondominio]` | string/int | `"0"` | Condominium identifier (`0` for all) |

#### Optional Supporting Filters:
| Parameter | Type | Example Values | Purpose |
|:---|:---|:---|:---|
| `imovel[codigocidade]` | string | `"timoteo"`, `"coronel-fabriciano"` | Filter listings by city slug |
| `imovel[numeroquartos]` | string | `"0-quartos"`, `"1-quartos"`, `"3-quartos"` | Minimum number of bedrooms |
| `imovel[numerovagas]` | string | `"0-vaga"`, `"1-vaga"`, `"2-vaga"` | Minimum number of parking spaces |
| `imovel[numerosuite]` | string | `"0-suite-ou-mais"`, `"1-suites"` | Minimum number of suites |
| `imovel[numerobanhos]` | string | `"0-banheiro-ou-mais"`, `"1-banheiro"` | Minimum number of bathrooms |
| `imovel[ordenacao]` | string | `"valordesc"`, `"valorasc"` | Price sorting preference |

### 2.2. Property Detail Endpoint

- **URL**: `POST https://www.minascaixaimoveis.com.br/imoveis/codigos/`
- **Content-Type**: `application/x-www-form-urlencoded`
- **Parameters**:
  - `codigo`: string with single ID (e.g. `"6161"`) or comma-delimited batch IDs (`"6161,7989"`).
  - `finalidade`: `"aluguel"` (optional).

#### Detail Response Schema:
Returns a `lista` array of full property records containing **219 attributes** per property including:
- **Identification**: `codigo`, `titulo`, `metadescription`, `unidade`, `nomeunidade`.
- **Financials**: `valor`, `valorminimo`, `valormaximo`, `valorcondominio`, `valoriptu`, `valorseguroincendio`.
- **Location**: `cidade`, `bairro`, `endereco`, `latitude`, `longitude`, `cep`.
- **Layout & Amenities**: `numeroquartos`, `numerobanhos`, `numerovagas`, `areainterna`, `areaprincipal`, plus dozens of boolean amenity flags (`piscina`, `academia`, `elevador`, etc.).
- **Media**: Complete `fotos` gallery array with high-resolution image URLs.

### 2.3. Filter Discovery Endpoints

- **Cities**: `POST https://www.minascaixaimoveis.com.br/cidadeAjax` (returns 26 cities with `nome`, `codigo`, `nomeOriginal`).
- **Neighborhoods**: `POST https://www.minascaixaimoveis.com.br/bairroAjax` with `cidade=timoteo` (returns 132 localities).
- **Property Types**: `POST https://www.minascaixaimoveis.com.br/tipoAjax` with `finalidade=aluguel` (returns 15 rental property types).
